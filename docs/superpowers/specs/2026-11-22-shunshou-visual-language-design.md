# 顺手 · 纸与墨：设计语言与周收支图表（第 2 版）

- 日期：2026-11-22（第 2 版，替换首版「便利贴手帐」暖纸方案）
- 范围：`src/` 全部 12 个路由 + `/today`「钱与时间的一周」图表
- 不在范围：`android/`、`local-sync/`、数据结构、用户可见文案、路由、aria、test id

## 1. 为什么改

首版用了「暖米纸 + 衬线大标题 + 赭红 + 胶带便利贴 + 荧光笔」——这正是 2025–2026 年 AI 生成界面的常见组合：暖奶油底、高对比衬线、赤陶色点缀，再加手作道具。用户反馈两轮：**「有点 AI 感」**、**「字体也要有设计」**。

第 2 版立三条规矩：

1. **不用 AI 套路**：冷白纸不用奶油色；不贴胶带、不旋转便签、不撒荧光笔；不做「每块内容一张等圆角卡」。
2. **排版是主角**：中文标题用思源宋体（衬线），界面与正文用思源黑体，金额与时长用宋体数字；字号、字重、行高、字距按级差写死。
3. **结构即信息**：数据区靠 1px 线与双线分段，卡片只留给可交互的块；数字右对齐、等宽。

## 2. 令牌（`src/styles.css` `:root`）

| 类别 | 值 |
|---|---|
| 纸 | `--page #f2f3ee`、`--paper-deep #e9eae1`、`--sheet #fdfdf9`、`--rule #e0e2d8`、`--rule-strong #c1c5b5` |
| 墨 | `--ink #1c1f1a`、`--ink-soft #464c43`、`--muted #666c60` |
| 色 | `--brand #2f5a45`、`--brand-deep #1f4030`、`--brand-wash rgba(47,90,69,.08)`、`--red #9e3b27`、`--red-deep #7d2c1b`、`--red-wash rgba(158,59,39,.07)`、`--note #f5f4ea`、`--warn #7a5420`、`--steel #4b6067` |
| 字 | `--font-ui`（Noto Sans SC / 苹方 / 雅黑）、`--font-display`（Noto Serif SC / 思源宋体 / 宋体）、`--font-figure`（同 display）、`--font-latin`（Bahnschrift） |
| 距 | `--s1 4` … `--s8 64` |
| 形 | `--r-sm 4`、`--r 6`、`--r-lg 8`；无投影（弹窗除外） |
| 动 | `--ease-out cubic-bezier(.2,.8,.2,1)`、`--dur 200ms`、`--dur-fast 120ms` |

语义：**收入 / 链接 / 主按钮 = 墨绿**；**支出 / 错误 = 印泥红**；**今日 = 红刻度 + 淡绿底**；**AI / 同步 = 钢蓝**；警示 = `--warn`。

对比度：`--muted` 在 `--sheet` 5.3:1、在 `--page` 4.8:1；`--red` 在 `--sheet` 6.6:1；`--brand` 7.8:1。

## 3. 排版

| 角色 | 字族 | 字号 / 字重 / 行高 |
|---|---|---|
| 首页 h1 | 思源宋体 | 32–42px / 600 / 1.28 / 字距 −0.01em |
| 页面 h1 | 思源宋体 | 24–31px / 600 / 1.32 |
| 区块 h2 | 思源黑体 | 16px / 600 / 1.5 / 字距 .01em |
| 小标题 h3 | 思源黑体 | 14.5px / 600 / 1.6 |
| 正文 | 思源黑体 | 14px / 400 / 1.8 |
| 说明 | 思源黑体 | 12–12.5px / 400 / 1.85，`--muted` |
| 微标签 | 思源黑体 | 11–11.5px，不加大字距 |
| 金额 / 时长 | 思源宋体 | 15–46px / 500–600，`lnum` + `tnum` |
| 键盘键 | Bahnschrift | 11px / 字距 .04em |

规矩：**只有 h1 用衬线**，其余标题黑体；所有钱与时长用宋体数字；中文标题加 `text-wrap: balance`；最小可见字号 11px。

## 4. 结构

- **外壳**：固定侧栏 232px（纸色、右侧 1px 线），品牌 = 印泥红方印 + 宋体「顺手」；导航选中 = 淡纸底 + 左侧墨绿刻度；顶栏 62px、1px 下边线。
- **数据区不套卡**：`planner-panel`、`chart-panel`、`recent-panel`、`ledger-panel`、`settings-panel` 用 1px 上边线分段，背景透明。
- **卡片只给交互块**：记一笔表单、单位、校园、专注、弹窗、旅行。
- **空态左对齐**，不做居中的打卡板。
- **合计条**：3px 双线压顶，宋体大数字，右对齐。
- **便利贴只剩一处**：侧栏「小事顺手记」，淡黄纸 + 一角轻折，无胶带、无投影。
- **图表**：中间基线、上收入下支出、同元/像素比；网格线 `--rule-strong` 55%，左侧 1px 轴线；今日列 8% 绿底 + 底部 3px 红刻度。

## 5. 图表规格（实现）

`records → summarize() → daily[7] → buildWeekChart()`；`topYuan = niceCeiling(max(收,支)/100)`；上下各两道网格 + 0 刻度；只标「本周最大收入、最大支出、今日两根」，柱高 <14px 不标；每列 `tabindex=0` + `aria-label`，悬停/聚焦弹 168px 明细卡，Esc 关闭；`figure` + 仅读屏图注 + `<details>` 真表格（7 行 × 日期/收入/支出/净额/工时）；全 0 周无 NaN（刻度 1 元）；动画 180ms，`prefers-reduced-motion` 关闭。
